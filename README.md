# Website Ucapan Ulang Tahun Interaktif

Website microsite ucapan selamat ulang tahun yang hangat, rapi, dan estetik untuk **Novia Lailia**. Dilengkapi dengan galeri momen foto, kue ulang tahun virtual dengan interaksi tiup lilin, pemutar musik otomatis lagu **Shape of My Heart**, dan buku tamu ucapan yang tersimpan ke file `wishes.json`.

---

## Fitur Utama:
1. **Galeri Foto:**
   - Menampilkan potret momen foto dengan bingkai polaroid estetik dan keterangan (*caption*) yang natural, sesuai dengan setiap foto.
2. **Karakter Asli Nailong sebagai Aset Visual:**
   - Menampilkan karakter animasi stiker Nailong sebagai elemen visual pemanis (maskot perayaan lilin dan avatar buku tamu), tanpa narasi berlebihan pada teks.
3. **Pesan Personal untuk Novia Lailia:**
   - Seluruh ucapan, doa, dan teks berfokus pada doa kebaikan, kesehatan, kebahagiaan, dan kesuksesan.
4. **Musik Otomatis ("Shape of My Heart"):**
   - Musik latar otomatis berputar (*autoplay*) saat website dibuka tanpa tombol putar musik yang mengganggu tampilan.
5. **Tiup Lilin Virtual Interaktif:**
   - Kue ulang tahun virtual dengan animasi padam dan asap realistis saat tombol "Tiup Lilin Sekarang" diklik, disertai suara dan semburan confetti perayaan.
6. **Buku Tamu Ucapan & Doa:**
   - Formulir pengiriman nama dan pesan ucapan yang langsung tersimpan ke `wishes.json` secara aman.

---

## Cara Menjalankan Project Secara Lokal:

### 1. Jalankan Server:
Buka terminal di folder project ini (`D:\Lailiaa\Ultah`) dan jalankan:
```bash
npm start
```

### 2. Buka di Browser:
Akses melalui:
```
http://localhost:3000
```
atau dengan parameter nama kustom:
```
http://localhost:3000/?nama=Novia+Lailia
```
