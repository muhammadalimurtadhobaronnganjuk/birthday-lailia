# 🗄️ Panduan Integrasi Supabase untuk Penyimpanan Data Ucapan Permanen

Panduan ini berisi langkah-langkah praktis dan mudah untuk menghubungkan website ulang tahun **Novia Lailia** ke **Supabase** agar seluruh doa dan ucapan tersimpan secara permanen (abadi), tidak akan hilang meskipun Vercel melakukan restart (*cold start*), redeploy, atau mode tidur.

---

## 🌟 Mengapa Menggunakan Supabase?

1. **100% Gratis Selamanya (Free Tier):**
   - Mendapatkan database cloud PostgreSQL berkecepatan tinggi tanpa perlu kartu kredit.
2. **Data Permanen & Aman:**
   - Tidak terpengaruh oleh sistem serverless Vercel yang sementara (*ephemeral*).
3. **Dashboard Visual Mudah Digunakan:**
   - Anda bisa melihat, mengedit, atau menghapus ucapan langsung dari browser melalui menu **Table Editor** Supabase seperti menggunakan Excel/Google Spreadsheet.

---

## 📋 Langkah Demi Langkah Setup Supabase

### Langkah 1: Buat Akun dan Project Baru di Supabase
1. Buka browser dan kunjungi: **[https://supabase.com](https://supabase.com)**
2. Klik tombol **"Start your project"** atau **"Sign In"**.
3. Pilih opsi **"Continue with GitHub"** (gunakan akun GitHub Anda).
4. Setelah masuk ke dashboard, klik tombol hijau **"New Project"**.
5. Isi formulir pembuatan project:
   - **Name:** `ultah-lailia` (atau nama lain sesuai keinginan).
   - **Database Password:** Buat password yang kuat (simpan jika sewaktu-waktu diperlukan).
   - **Region:** Pilih wilayah terdekat, misalnya **Singapore (ap-southeast-1)** agar akses dari Indonesia super cepat.
   - **Pricing Plan:** Pilih **Free** ($0/month).
6. Klik tombol **"Create new project"**.
7. Tunggu sekitar 1–2 menit sampai proses penyiapan server database selesai.

---

### Langkah 2: Buat Tabel `wishes` Menggunakan SQL Editor
1. Di dashboard Supabase project Anda, klik menu **SQL Editor** (ikon lembaran kode `>_` di bilah sisi kiri).
2. Klik tombol **"New query"** (atau tanda `+`).
3. Salin (copy) seluruh kode SQL berikut dan tempel (paste) ke editor:

```sql
-- 1. Buat tabel wishes jika belum ada
CREATE TABLE IF NOT EXISTS public.wishes (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name TEXT NOT NULL,
  message TEXT NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 2. Aktifkan Row Level Security (RLS) demi keamanan
ALTER TABLE public.wishes ENABLE ROW LEVEL SECURITY;

-- 3. Hapus policy lama jika pernah dibuat (agar tidak duplikat)
DROP POLICY IF EXISTS "Izinkan Siapa Saja Membaca Ucapan" ON public.wishes;
DROP POLICY IF EXISTS "Izinkan Siapa Saja Mengirim Ucapan" ON public.wishes;

-- 4. Buat Policy agar pengunjung publik dapat membaca ucapan
CREATE POLICY "Izinkan Siapa Saja Membaca Ucapan"
ON public.wishes
FOR SELECT
TO anon, authenticated
USING (true);

-- 5. Buat Policy agar pengunjung publik dapat mengirimkan ucapan baru
CREATE POLICY "Izinkan Siapa Saja Mengirim Ucapan"
ON public.wishes
FOR INSERT
TO anon, authenticated
WITH CHECK (true);

-- 6. Masukkan ucapan awal sebagai contoh
INSERT INTO public.wishes (name, message, created_at)
VALUES ('Ali', 'Selamat ulang tahun cantik!', '2026-11-14T13:21:00.678Z')
ON CONFLICT DO NOTHING;
```

4. Klik tombol hijau **"Run"** di pojok kanan bawah editor.
5. Pesan sukses **"Success. No rows returned"** akan muncul. Tabel `wishes` Anda sudah siap 100%!

---

### Langkah 3: Ambil Kredensial URL & API Key Supabase
1. Di bilah menu sisi kiri bawah, klik menu **Project Settings** (ikon roda gigi ⚙️).
2. Pilih submenu **"API"** (atau **Data API**).
3. Anda akan melihat dua informasi penting di bagian **Project URL** dan **Project API Keys**:
   - **Project URL:** Contohnya `https://abcdefghijklm.supabase.co` (⚠️ **Penting:** Pastikan TIDAK menyertakan akhiran `/rest/v1` atau `/rest/v1/` di belakang URL).
   - **anon / public key:** String panjang yang diawali dengan `eyJhbGciOi...` atau `sb_publishable_...`
4. Biarkan tab browser ini tetap terbuka atau salin kedua nilai tersebut ke Notepad.

---

### Langkah 4: Pasang Kredensial di Vercel (Production)
Agar website Anda yang sudah live di Vercel dapat membaca dan menyimpan ucapan ke Supabase:

1. Buka dashboard Vercel: **[https://vercel.com/dashboard](https://vercel.com/dashboard)**.
2. Klik nama project Anda (misalnya `ultah-lailia`).
3. Masuk ke tab **Settings** di bagian atas, lalu pilih menu **Environment Variables** di bilah kiri.
4. Tambahkan 2 variabel berikut satu per satu:

   - **Variabel 1:**
     - **Key:** `SUPABASE_URL`
     - **Value:** *(Tempelkan Project URL dari Langkah 3)*
     - **Target:** Centang semua (Production, Preview, Development)
     - Klik **"Save"**.

   - **Variabel 2:**
     - **Key:** `SUPABASE_ANON_KEY`
     - **Value:** *(Tempelkan anon public key dari Langkah 3)*
     - **Target:** Centang semua (Production, Preview, Development)
     - Klik **"Save"**.

5. **Lakukan Redeploy agar Vercel memuat variabel baru:**
   - Masuk ke tab **Deployments** di Vercel.
   - Klik tombol titik tiga (**...**) pada deployment terbaru yang sedang aktif.
   - Pilih **"Redeploy"**.
   - Tunggu sekitar 20–30 detik sampai selesai.

---

### Langkah 5: (Opsional) Uji Coba di Komputer Lokal
Jika Anda ingin mencoba menjalankan server di laptop secara offline terlebih dahulu:
1. Buat file bernama `.env` di folder project (`D:\Lailiaa\Ultah\.env`).
2. Isi file tersebut dengan format:
   ```env
   SUPABASE_URL=https://abcdefghijklm.supabase.co
   SUPABASE_ANON_KEY=eyJhbGciOi...isi_anon_key_kamu...
   ```
3. Buka terminal dan jalankan:
   ```powershell
   npm start
   ```
4. Buka browser di `http://localhost:3000` dan coba kirim ucapan. Ucapan akan langsung terkirim ke Supabase!

---

### Langkah 6: Upload Perubahan Kode ke GitHub
Pastikan file kode terbaru yang sudah diintegrasikan dengan Supabase terkirim ke repository GitHub Anda:

Jalankan perintah berikut di terminal PowerShell:

```powershell
git add .
git commit -m "Integrasi Supabase untuk database ucapan permanen"
git push origin main
```

*(Setelah di-push ke GitHub, Vercel akan otomatis melakukan build dan deploy versi terbaru).*

---

### 🔍 Cara Mengecek Ucapan yang Masuk di Supabase
1. Buka dashboard Supabase.
2. Klik menu **Table Editor** (ikon tabel di bilah sisi kiri).
3. Klik tabel **`wishes`**.
4. Anda dapat melihat semua nama pengirim, pesan doa, dan tanggal pengiriman secara real-time. Anda juga bisa menghapus ucapan tertentu jika ada kata-kata iseng atau typo.
